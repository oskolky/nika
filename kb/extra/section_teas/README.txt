# Предметная область «Чаи» для ЛР №1

Вариант 55.

Структура:
- section_teas.scs — описание предметной области;
- concepts/ — абсолютные понятия;
- relations/ — исследуемые бинарные отношения;
- instances/ — экземпляры и фактические связи.

Перед использованием:
1. Скопировать папку section_teas в `kb/extra/`.
2. Пересобрать базу знаний NIKA.
3. Проверить запросы «Что такое зелёный чай?» и «Каким бывает чай?».
