# Классификация сообщений (Лабораторная работа №2)

Предметная область: **«Чаи»** (вариант 55), раздел `kb/extra/section_teas`.

## Содержимое папки

- `wit_ai_export.json` — экспорт приложения wit.ai (intent `about_entity`,
  сущность `rrel_entity`, 158 обучающих фраз для 57 сущностей предметной области);
- `utterances.txt` — те же обучающие фразы списком (для ввода вручную).

## Настройка wit.ai

1. Зайдите на https://wit.ai и войдите через Facebook.
2. Создайте новое приложение: имя — `nika-teas`, язык — `Russian`,
   приватность — `Private`.
3. Вкладка **Management → Intents**: создайте intent `about_entity`.
4. Вкладка **Management → Entities**: создайте сущность `rrel_entity`
   (используется одна роль — `rrel_entity`).
5. Вкладка **Understanding**: по очереди вводите фразы из `utterances.txt`,
   выбирайте intent `about_entity` и выделяйте сущность в фразе,
   назначая ей роль `rrel_entity`. Сущности лучше выделять в именительном
   падеже (все фразы уже составлены таким образом).
6. Дождитесь окончания обучения (индикатор в левом верхнем углу) и
   проверьте классификацию новых фраз в поле ввода.

## Подключение к системе NIKA

1. В настройках приложения wit.ai скопируйте **Server Access Token**.
2. Запишите его в `nika.ini` (в корне репозитория):

```ini
[wit-ai]
server_token = <ВАШ_ТОКЕН>
url = https://api.wit.ai/message
```

3. Пересоберите и перезапустите NIKA, откройте диалоговое окно.
4. Проверьте ответы на вопросы «Что такое …?» для сущностей предметной
   области, например: «Что такое чай?», «Что такое улун?»,
   «Что такое сенча?», «Что такое кофеин?».

Класс сообщения `concept_message_about_entity` (wit id `about_entity`) и
множество `concept_intent_possible_class` уже формализованы в базе знаний
(`kb/non_subject_domain_concepts/wit/concept_intent_possible_class.scs`),
поэтому вносить изменения в БЗ не требуется.

## Публикация результатов

После обучения на wit.ai выполните **Settings → Export data** и сохраните
полученный экспорт в эту папку вместо `wit_ai_export.json`, затем:

```bash
git add kb/extra/
git commit -m "feat(kb): чаи — классификация сообщений wit.ai"
git push
```
